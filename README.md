# color-wall-raid-prototype

一个基于 `Phaser` 的广告还原型拆墙射击小游戏原型。

目标不是做完整商业游戏，而是先把这类短视频广告里最核心的爽感跑通：

- 点击底部待命小兵
- 自动补到最合适的战斗席位
- 持续向正前方障碍墙射击
- 墙体逐层碎裂、整列清空、最终过关

## 当前状态

当前仓库已经实现了一个可在电脑浏览器中直接游玩的最小原型：

- 固定 `5` 个战斗席位
- `5` 列障碍墙
- 底部待命小兵池
- 自动补位规则
- 小兵上阵跳跃动画
- 自动开火与同列最近目标锁定
- 墙体受击、碎裂、清列反馈
- 单局胜利 / 失败判定
- 重新开始流程

## 本地运行

先安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

默认会启动一个本地 Vite 页面，在浏览器打开对应地址即可游玩。

## 可用脚本

运行测试：


执行构建检查：

```bash
npm run build
```

## 玩法说明

1. 点击底部任意一个待命小兵。
2. 系统会把它自动补到当前最优空位。
3. 小兵上阵后会持续攻击自己正前方那一列障碍。
4. 清空全部障碍墙即胜利。
5. 待命小兵耗尽且火力断档时失败。

当前自动补位规则是：

- 优先选择空席位
- 多个空席位时，优先补到“剩余障碍总耐久最高”的列
- 如果仍相同，则按从左到右补位

```text
src/

  game/
    GameScene.ts       # Phaser 主场景、输入、表现与胜负流程

tests/
  gameLogic.test.ts    # 自动补位、目标选择、伤害推进测试
```

## 下一步建议

如果继续往下做，比较自然的方向有这几类：

- 更像广告：补粒子、屏幕震动、命中特效、音效
- 更好玩：加入多兵种、列间差异、轻数值成长
- 更像产品：加入关卡切换、首页、结算页、进度保存
- 更像素材：把当前程序图形替换成更统一的角色与障碍美术
