# color-wall-raid-prototype

一个基于 `Phaser` 的广告还原型拆墙射击小游戏原型。

目标不是做完整商业游戏，而是先把这类短视频广告里最核心的爽感跑通：

- 点击底部待命小兵
- 自动补到最合适的战斗席位
- 持续向全场最近的同色障碍墙射击
- 墙体沿斜向战场逐步碎裂、最终过关

## 当前状态

当前仓库已经实现了一个可在电脑浏览器中直接游玩的最小原型：

- 固定 `5` 个战斗席位
- 斜向透视战场与球堆式城墙表现
- 底部待命小兵池
- 同色优先、可回退到任意空位的自动补位
- 小兵上阵跳跃动画
- 全局同色目标锁定与最近目标优先
- 弹药消耗、弹尽退场、席位释放
- 墙体受击、碎裂、清场反馈
- 单局胜利 / 失败判定
- 重新开始流程

先安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

默认会启动一个本地 Vite 页面，在浏览器打开对应地址即可游玩。

## 玩法说明

1. 点击底部任意一个待命小兵。
2. 系统会把它自动补到当前最优空位。
3. 小兵上阵后会持续攻击全场最近的同色障碍。
4. 清空全部障碍墙即胜利。
5. 小兵头顶数字表示剩余子弹，打完后立即退场。
6. 待命小兵无法再改变结果且场上火力断档时失败。

当前自动补位规则是：

- 永远优先填充当前最左侧的空席位
- 如果最左席位被占，则继续找下一个从左到右的空席位
- 预备兵颜色不会影响补位顺序

当前目标选择规则是：

- 只攻击同色城墙
- 可跨列攻击，不限制在面前一列
- 在可攻击目标中优先选择视觉上最近的同色墙

    level.ts           # 关卡与单位基础配置

tests/
  gameLogic.test.ts    # 自动补位、目标选择、伤害推进测试

## 下一步建议

如果继续往下做，比较自然的方向有这几类：

- 更像广告：补粒子、屏幕震动、命中特效、音效
- 更好玩：加入多兵种、列间差异、轻数值成长
- 更像产品：加入关卡切换、首页、结算页、进度保存
- 更像素材：把当前程序图形替换成更统一的角色与障碍美术
