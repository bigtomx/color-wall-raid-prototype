# Target View Notes

This file is a text-only summary of `docs/reference/target-view.jpg` for environments that cannot read image input.

## Board / Camera

- The board is shown in a slanted side + top-down perspective, not a flat straight-on lane view.
- The playfield feels like a rectangular tray receding upward into depth.
- Columns look like diagonal depth rows, with stronger perspective compression toward the top.

## Walls / Targets

- Obstacles are made of dense colored ball-like stacks rather than flat wall blocks.
- Large color regions are grouped by color across the board: purple on the left, lime green on the upper-right, dark gray on both lower sides, white in the center, with red accents / borders between regions.
- The board reads as a whole color field, not five isolated vertical lanes.

## Units / Reserve

- Reserve soldiers are arranged below the board in multiple diagonal color-coded lines.
- Unit colors visually match target colors.
- A finger is tapping one reserve unit, emphasizing click-to-deploy from the bottom pool.

## Combat Feel

- Attacks create splashy white impact streaks and debris near the lower front edge of the board.
- The visual fantasy is that same-color units join a global color-clearing effort across the whole board, instead of only shooting the tile directly ahead in one lane.

## What To Approximate In The Prototype

- Shift the current layout toward an isometric / slanted depth composition.
- Keep reserve units clearly separated below the board.
- Make battlefield targeting feel board-wide by color.
- It is acceptable to keep the current minimal art style as long as layout, depth, and targeting behavior move closer to this reference.
